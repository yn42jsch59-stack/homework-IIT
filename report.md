\## Дополнительное задание: динамический сайт

GitHub Pages является хостингом только для статических сайтов. Он не поддерживает серверные языки (PHP, Node.js) и базы данных, поэтому динамический сайт разместить напрямую нельзя.

Для решения этой задачи можно использовать GitHub Actions. Настроенный workflow-файл будет при каждом push собирать проект и деплоить его на внешний хостинг, поддерживающий backend (например, Vercel, Render или собственный сервер). Альтернативный вариант — использовать GitHub только как хранилище кода, а развёртывание выполнять на стороне хостинг-провайдера.
